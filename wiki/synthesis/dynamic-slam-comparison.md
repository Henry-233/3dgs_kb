## 概述

SLAM系统在动态环境（运动物体）和退化条件（噪声、低光）下性能急剧下降。以下方法从不同角度解决鲁棒性问题，可沿三个正交维度分类：

- **检测时机**：跟踪侧（实时mask） vs 建图侧（渲染误差反馈） vs 特征侧（多视图一致性）
- **时序建模**：逐帧 vs 时序窗口 vs 训练后固定
- **表示**：3DGS vs 点云

## 核心差异一览

### 3DGS路线（跟踪侧动态检测）

| 维度 | Dy3DGS-SLAM | ADD-SLAM | WildGS-SLAM |
|------|------------|----------|-------------|
| **检测方式** | 概率融合（光流+深度mask） | 场景一致性分析+MobileSAM | MLP+DINOv2预测不确定性 |
| **时序建模** | 无（逐帧概率融合） | 无（逐帧渲染vs观测） | 无（逐帧特征） |
| **需要训练** | 否（前向推理） | 否 | 是（DINOv2预训练） |
| **需要深度** | 单目估计（Depth Anything v2） | 否 | 否 |
| **动态物体处理** | 过滤（深度=∞剪枝） | **时序高斯建模**（保留动态信息） | 过滤（不确定性加权） |
| **关键创新** | 贝叶斯融合+单次迭代 | 渲染vs观测一致性 | 建图侧不确定性 |
| **跟踪架构** | ResNet50 + 运动损失 | DBA + 动态掩码 | DBA + 不确定性 |
| **Bonn ATE** | 4.5 cm | 2.8 cm | 2.9 cm |
| **TUM ATE** | 4.7 cm | 1.3 cm | 1.4 cm |

### 3DGS路线（建图侧/时序动态检测）

| 维度 | GGD-SLAM | UP-SLAM | RoGER-SLAM |
|------|---------|---------|------------|
| **检测方式** | GMM（FIFO+时序注意力） | 多模态残差不确定性估计器 | SP-RoFusion多模态融合 |
| **时序建模** | **是**（L=12 FIFO队列） | 无 | 无 |
| **需要训练** | 是（Davis预训练GMM） | 否 | 否 |
| **需要深度** | 否（纯单目RGB） | 否 | RGB-D |
| **动态物体处理** | 过滤+KD-tree遮挡恢复 | 过滤 | N/A（非动态聚焦） |
| **关键创新** | 干扰自适应SSIM | 概率八叉树+并行架构 | CLIP增强+残差平衡 |
| **跟踪架构** | DROID-SLAM DBA + GMM先验 | 并行跟踪-建图 | 自适应跟踪+残差平衡 |
| **Bonn ATE** | 2.7 cm | 3.2 cm | 0.60 cm (Replica噪声+低光) |
| **TUM ATE** | 1.3 cm | 1.4 cm | 2.63 cm (TUM噪声+低光) |

### 非3DGS路线（特征侧不确定性）

| 维度 | DROID-SLAM in the Wild |
|------|----------------------|
| **检测方式** | 多视图特征不一致性→可微UBA |
| **时序建模** | 迭代优化（非学习式） |
| **需要训练** | 否（DINOv2+冻结DROID特征） |
| **需要深度** | 单目估计（Metric3D） |
| **动态物体处理** | BA残差降权（1/u权重） |
| **关键创新** | 特征侧不确定性——不依赖建图质量 |
| **表示** | 点云（非3DGS） |
| **跟踪架构** | DROID-SLAM + 交替UBA优化 |
| **Bonn ATE** | **2.30 cm** (最佳整体) |
| **TUM ATE** | **1.36 cm** (最佳整体) |

## 动态检测方法演进

```
WildGS-SLAM (2025.04)
  └─ 建图侧不确定性：MLP+DINOv2预测逐像素不确定性
     └─ 问题：需要稳定地图来优化不确定性→杂乱场景恶性循环
        │
        ├──► Dy3DGS-SLAM (2025.06)
        │    └─ 跟踪侧概率融合：光流+深度mask贝叶斯融合
        │       单次迭代，FPS 17.0，无需在线训练
        │       问题：逐帧处理，无法检测"跨帧静态但长期移动"物体
        │
        ├──► ADD-SLAM (2025.05)
        │    └─ 渲染侧场景一致性：渲染vs观测比较
        │       + 时序高斯建模（唯一保留动态信息的方法）
        │       问题：依赖MobileSAM，逐帧一致性分析
        │
        ├──► GGD-SLAM (2026)
        │    └─ 时序建模：FIFO(L=12)+时序注意力→可泛化运动模型
        │       + 干扰自适应SSIM + KD-tree遮挡恢复
        │       优势：跨帧学习"什么是运动"，检测逐帧静态但长期移动的物体
        │       问题：需Davis数据集预训练GMM
        │
        ├──► UP-SLAM (2025.05, ICRA 2026)
        │    └─ 多模态残差不确定性估计器（无训练）
        │       + 概率八叉树 + 并行架构
        │
        └──► DROID-SLAM in the Wild (2026.03, CVPR 2026)
             └─ **特征侧不确定性**：多视图DINOv2特征一致性→可微UBA
                完全绕过建图环节——不依赖高斯/NeRF建图质量
                交替优化：位姿-深度精化 ↔ 不确定性优化
                问题：非3DGS表示→无照片级渲染能力；~10 FPS
```

## 关键洞察

### 1. 从"建图侧"到"跟踪侧"到"特征侧"——不确定性优化的三次范式转移

- **建图侧**（WildGS-SLAM）：先建图→用渲染误差优化不确定性→重建图。恶性循环：地图差→不确定性差→地图更差。
- **跟踪侧**（Dy3DGS-SLAM, ADD-SLAM）：在建图前识别动态区域，避免动态像素污染地图。但逐帧处理，无时序上下文。
- **跟踪侧+时序**（GGD-SLAM）：通过FIFO队列为跟踪侧检测提供时序上下文。但需要预训练。
- **特征侧**（DROID-W）：直接在特征空间测量"是否违反刚性运动"，完全绕过地图构建。地图无关——最鲁棒但牺牲渲染能力。

### 2. 从语义先验到运动检测——"先验自由"已成共识

全部7篇动态SLAM方法都抛弃了预定义动态类别（YOLO/SAM语义分割），转向直接检测"运动"本身。检测手段分化：
- 概率融合（Dy3DGS-SLAM）
- 渲染一致性（ADD-SLAM）
- 特征不确定性（WildGS-SLAM, UP-SLAM）
- 时序注意力（GGD-SLAM）
- 多视图特征不一致性（DROID-W）

### 3. 过滤 vs 建模——动态SLAM的终极分歧

- **过滤派**（6/7方法）：识别动态区域→移除/降权→只重建静态背景
- **建模派**（ADD-SLAM）：识别动态区域→用时序高斯建模→重建"静态背景+动态物体"

ADD-SLAM是唯一主动建模动态物体的方法——这对机器人交互（抓取移动物体、避让行人）至关重要。

### 4. 3DGS vs 非3DGS——鲁棒性与渲染质量的权衡

- **3DGS路线**（6/7）：高保真渲染+新视角合成，但建图质量直接影响动态检测
- **非3DGS路线**（DROID-W）：点云输出→最鲁棒的跟踪，但无照片级渲染

理想系统可能需要在两种表示间切换：动态场景用DROID-W跟踪，静态区域用3DGS渲染。
