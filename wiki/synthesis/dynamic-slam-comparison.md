## 概述

3DGS-SLAM在静态场景中表现出色，但在动态环境（运动物体）和退化条件（噪声、低光）下性能急剧下降。以下四篇论文从不同角度解决鲁棒性问题。

## 核心差异一览

| 维度 | WildGS-SLAM | ADD-SLAM | UP-SLAM | RoGER-SLAM |
|------|------------|----------|---------|------------|
| **鲁棒目标** | 动态物体 | 动态物体+动态建模 | 动态物体 | 噪声+低光照 |
| **检测方式** | MLP+DINOv2预测不确定性 | 场景一致性分析+MobileSAM | 多模态残差不确定性估计器 | SP-RoFusion多模态融合 |
| **是否需要先验** | 否 | 否 | 否 | 否 |
| **语义基础模型** | DINOv2 | MobileSAM | DINO features | CLIP |
| **动态物体处理** | 过滤（不确定性加权） | **时序高斯建模** | 过滤 | N/A（非动态聚焦） |
| **跟踪-建图架构** | 顺序 | 顺序 | **并行** | 顺序 |
| **场景表示管理** | 标准3DGS | 标准3DGS | **概率八叉树** | 标准3DGS |
| **关键帧优化** | Dense BA+不确定性 | DBA+动态掩码 | — | 自适应跟踪+残差平衡 |
| **退化条件** | 一般 | 一般 | 一般 | **专门设计**（CLIP增强） |

## 动态检测方法演进

```
WildGS-SLAM (2025.04)
  └─ 不确定性感知：MLP+DINOv2预测逐像素不确定性
     └─ 问题：边界模糊、短序列MLP训练不充分
        │
        ├──► ADD-SLAM (2025.05)
        │    └─ 场景一致性分析：渲染vs观测 → 几何/颜色不一致
        │       + MobileSAM精细分割 → 精确边界
        │       + 动态物体建模（时序高斯）→ 保留动态信息
        │       问题：依赖MobileSAM，无并行架构
        │
        └──► UP-SLAM (2025.05, ICRA 2026)
             └─ 多模态残差不确定性估计器（无训练）
                + 概率八叉树自适应管理
                + 并行跟踪-建图架构
                问题：仍过滤动态物体，不建模
```

## 关键洞察

1. **从语义先验到运动检测**：三篇论文都抛弃了预定义动态类别，转向直接检测"运动"本身——WildGS-SLAM用不确定性、ADD-SLAM用一致性分析、UP-SLAM用多模态残差

2. **过滤 vs 建模**：ADD-SLAM是唯一一个不只过滤、而是主动建模动态物体的方法，这对机器人交互至关重要

3. **架构演进**：顺序优化（WildGS-SLAM, ADD-SLAM）→ 并行跟踪-建图（UP-SLAM），提升实时性

4. **鲁棒性多维度**：动态物体（3篇）和传感器退化（RoGER-SLAM）是正交的鲁棒性维度，理想系统需要同时处理两者
