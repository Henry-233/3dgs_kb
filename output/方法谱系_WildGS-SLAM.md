# WildGS-SLAM 方法谱系

## Baseline 概述

**WildGS-SLAM** (Zheng et al., arXiv 2025) 是首个仅用单目RGB即可在动态环境中鲁棒运行的3DGS-SLAM系统。

**核心思路：** DINOv2（3D-aware微调）提取图像特征 → 在线训练浅层MLP预测逐像素"不确定性图" → 不确定性同时加权跟踪（DBA光流重投影误差除以β²，动态物体不影响位姿）和建图（渲染损失除以β²，动态区域不影响场景重建）。无需深度传感器、无需语义分割、无需预定义物体类别。

**关键贡献：**
- 首次将不确定性感知范式引入3DGS-SLAM的动态场景处理
- DINOv2 + 在线MLP的不确定性预测方案——边看边学，无需标注
- Metric3D v2单目深度作为视差正则化锚点，解决MLP冷启动问题

**关键局限：**
1. 不确定性MLP依赖多视图一致性——观测不足时无法判断动态性
2. 在线训练冷启动：初始帧MLP未训练，依赖深度先验维持
3. 速度慢：完整版 <1 FPS（DINOv2 + MLP + 不确定性加权开销）
4. 仅过滤动态物体，不建模——丢弃了机器人交互所需信息
5. 仅单目RGB，不利用深度传感器信息
6. 依赖预训练模型（DINOv2, Metric3D v2）的泛化能力

**Wild-SLAM MoCap ATE 2.40 cm，Bonn Dynamic 2.31 cm，TUM Dynamic 1.63 cm。**

## 基于该Baseline的改进方向

### 方向一：动态检测质量 —— 从"模糊不确定性"到"精确分割"

- **ADD-SLAM** (Wu et al., arXiv 2025)：指出WildGS-SLAM的不确定性图在动态物体边界处模糊、短序列MLP训练不充分。改用**场景一致性分析**——直接比较渲染与观测的几何/颜色差异，通过深度方向区分动态物体（遮挡背景→观测深度<渲染深度）与新暴露背景，再以MobileSAM精修边界。在DAVIS数据集上边界显著优于WildGS-SLAM。同时增加**时序高斯动态建模**——不丢弃动态物体，而是为每个动态物体构建独立高斯场持续追踪。Bonn ATE 2.77 cm（WildGS-SLAM RGBD 2.88 cm），动态分割68.8 ms（WildGS-SLAM需整个MLP在线训练流程）。

- **UP-SLAM** (Zheng et al., ICRA 2026)：指出WildGS-SLAM的不确定性估计依赖预训练DINOv2和在线MLP训练（训练依赖、冷启动问题）。改用**训练无关的不确定性估计**——直接在跟踪线程中优化不确定性图，利用3DGS快速渲染能力比较渲染与观测残差，无需任何预训练模型或在线训练。同时引入**并行跟踪-建图架构**（WildGS-SLAM为顺序流水线），处理速率12 FPS vs WildGS-SLAM 0.5 FPS（约24倍加速）。Bonn ATE 1.06 cm。

### 方向二：不确定性估计方法 —— 从"预训练预测器"到"可学习/免训练方差"

- **VarSplat** (Tran & Kosecka, arXiv 2026)：与WildGS-SLAM同在"不确定性"范式下但走相反路线。WildGS-SLAM用**预训练DINOv2 + MLP**预测不确定性（需要外部模型，不能端到端适配场景）；VarSplat用**在线可学习的外观方差σ²**——为每个3D高斯增加σ²作为参数，通过全方差定律在Alpha合成中单pass渲染逐像素不确定性V，用高斯负对数似然端到端学习。核心区别：WildGS-SLAM的β来自"图像特征解码器"（2D侧），VarSplat的σ²来自"3D高斯自身参数"（3D侧）。VarSplat的方差用于跟踪光度加权（而非动态过滤），与WildGS-SLAM的应用方向不同但技术互补。ScanNet++ ATE 1.69 cm。

- **UP-SLAM**（同上，跨两个方向）：不确定性估计完全免训练——在跟踪线程通过优化逐像素残差图直接获得不确定性，既不需要DINOv2也不需要在线MLP。与WildGS-SLAM的DINOv2方案对比：训练时间 0 vs 需MLP收敛；泛化性 任意场景 vs 受DINOv2域限制；速度 快（12 FPS）vs 慢（0.5 FPS）。

### 方向三：跟踪架构 —— 从"优化式DBA"到"并行/前馈"

- **UP-SLAM**：将WildGS-SLAM的顺序跟踪-建图改造为**并行双线程**——跟踪线程实时处理每帧（含不确定性估计），建图线程异步优化高斯地图。这是对WildGS-SLAM架构层面的根本改进，不改变不确定性感知的核心思想。

- **Pseudo Depth Meets Gaussian** (Zhao et al., arXiv 2025)：将WildGS-SLAM的优化式DBA跟踪替换为**前馈式位姿预测**——训练一个网络直接从RGB-D输入预测相机位姿，替代逐帧迭代优化。跟踪时间减少90%，但需要训练且泛化性受限。

### 方向四：鲁棒性范围扩展 —— 从"动态场景"到"多维鲁棒性"

- **RoGER-SLAM** (Yin et al., arXiv 2025)：与WildGS-SLAM正交互补。WildGS-SLAM处理**场景动态**（运动物体破坏一致性），RoGER-SLAM处理**传感器退化**（噪声+低光破坏输入质量）。RoGER-SLAM明确指出现有方法（含WildGS-SLAM）在噪声+低光下性能崩溃（SplaTAM恶化19倍），且其局限中写明"需与WildGS-SLAM/ADD-SLAM结合处理动态物体"。两者联合可覆盖"输入退化+场景动态"的完整鲁棒性。

- **Taming the Light** (Zhang et al., arXiv 2025)：与WildGS-SLAM在不同维度互补。WildGS-SLAM处理"什么在动"（动态物体），Taming the Light处理"光怎么变"（光照不变性）。IAN量化解耦反照率/光照的思路与WildGS-SLAM的不确定性过滤可以共存——IAN保证颜色一致性，不确定性保证运动鲁棒性。

- **TVG-SLAM** (Tan et al., arXiv 2025)：与WildGS-SLAM在不同场景互补。WildGS-SLAM聚焦室内动态场景（TUM/Bonn），TVG-SLAM聚焦室外几何退化（Waymo/Cambridge）。TVG-SLAM的三视图几何约束是"地图无关"的稳定锚点——当地图因任何原因（含动态物体）不可靠时，几何约束仍有效。

### 方向五：深度先验质量 —— 从"相对深度锚点"到"度量深度"

- **ViMGS-SLAM** (Array 2026)：WildGS-SLAM使用Metric3D v2预测**相对深度**作为视差正则化锚点（需额外尺度对齐步骤）。ViMGS-SLAM用多尺度Vision Transformer（MViT）直接预测**度量深度**，替代相对深度+尺度对齐流程。PSNR 39.6 dB（大幅超过WildGS-SLAM的渲染质量），但不专门处理动态场景——深度先验质量的提升与动态鲁棒性是正交改进。

## 方法演进时间线

```
2024 ─── MonoGS (静态假设, CVPR 2024)
           │
           ├── Splat-SLAM (增加回环+全局BA, 仍静态假设, 2024)
           │
2025 ─── WildGS-SLAM (首次动态鲁棒单目3DGS-SLAM, arXiv 2025.04)
           │  核心范式: DINOv2 → 在线MLP → 不确定性图 → 加权跟踪+建图
           │
           ├── 动态检测改进 ─── ADD-SLAM (2025.05, 一致性分析替代不确定性, +动态建模)
           │                     UP-SLAM (2025.05→ICRA 2026, 免训练不确定性, 并行架构)
           │
           ├── 不确定性方法改进 ─── VarSplat (2026, 在线学习外观方差替代预训练预测器)
           │                        UP-SLAM (同上, 免训练不确定性优化)
           │
           ├── 架构改进 ─── UP-SLAM (并行跟踪-建图, 24倍加速)
           │                 Pseudo Depth (前馈位姿预测, 90%跟踪时间减少)
           │
           ├── 深度先验改进 ─── ViMGS-SLAM (2026, MViT度量深度替代Metric3D v2相对深度)
           │
           └── 鲁棒性互补 ─── RoGER-SLAM (2025, 噪声/低光鲁棒)
                            Taming the Light (2025, 光照不变)
                            TVG-SLAM (2025, 室外几何约束)
```

## 各方法对比

| 方法 | 解决baseline哪个问题 | 引入的代价/局限 | 适用场景 |
|------|-------------------|--------------|---------|
| **ADD-SLAM** | 不确定性边界模糊 + 丢弃动态信息 | 依赖MobileSAM分割质量；首帧需静态初始化 | 室内动态场景，需建模动态物体的交互任务 |
| **UP-SLAM** | MLP训练依赖+冷启动 + 顺序架构慢 | 需RGB-D（WildGS-SLAM仅单目）；训练无关可能不如学习方案在极端情况鲁棒 | RGB-D动态场景，实时性要求高（12 FPS） |
| **VarSplat** | 预训练DINOv2不可端到端学习 + 仅2D侧不确定性 | 每高斯+3参数；仅外观方差（未建模几何方差）；深度依赖初始化 | RGB-D室内，需测量级不确定性量化的场景 |
| **Pseudo Depth** | 迭代DBA跟踪慢 | 需训练前馈网络；泛化性受限；非动态场景专门设计 | 已知环境中的快速重定位 |
| **ViMGS-SLAM** | Metric3D v2仅相对深度需尺度对齐 | ViT推理开销；不专门处理动态场景 | 需高质量深度先验的单目SLAM |
| **RoGER-SLAM** | 不处理传感器噪声/低光 | RGB-D依赖；CLIP需预训练；不处理动态物体 | 噪声/低光环境（与动态处理方法组合） |
| **Taming the Light** | 不处理极端曝光变化 | 64色palette丢失纹理；仅室内验证；不处理动态 | 光照剧变室内场景 |
| **TVG-SLAM** | 不处理室外几何退化 | 稠密匹配400ms瓶颈；RGB-only；不处理动态物体 | 室外大场景，RGB-only |

## 仍未解决的问题

1. **统一鲁棒性系统**：没有单一系统同时具备——动态物体鲁棒性（WildGS-SLAM/ADD-SLAM/UP-SLAM）+ 传感器退化鲁棒性（RoGER-SLAM）+ 光照不变性（Taming the Light）+ 几何约束（TVG-SLAM）+ 测量不确定性（VarSplat）。每个维度的方法都引入了互不兼容的假设（RGB-only vs RGB-D、室内 vs 室外、静态初始化 vs 在线适应）。

2. **动态物体的"检测-建模-预测"闭环**：WildGS-SLAM和UP-SLAM仅过滤动态物体；ADD-SLAM开始建模但每帧独立优化，无运动预测。一个完整方案应包含：检测（不确定性/一致性）→ 建模（时序高斯）→ 预测（运动模型辅助跟踪）。

3. **不确定性预测的"冷启动"问题**：WildGS-SLAM依赖视差正则化度过冷启动，ADD-SLAM假设首帧静态，UP-SLAM需要在跟踪线程额外优化。如何在第一帧就获得可靠的不确定性估计，仍未有优雅解决方案。

4. **单目动态SLAM的深度-不确定性耦合**：WildGS-SLAM用Metric3D v2的相对深度辅助不确定性MLP训练——深度误差会放大不确定性误差。ViMGS-SLAM改进了深度质量但未闭环反馈到不确定性。深度先验与不确定性预测的联合优化是未探索方向。

5. **计算效率 vs 鲁棒性覆盖的权衡**：每增加一个鲁棒性维度，计算开销累加（DINOv2 + MLP + CLIP增强 + 稠密匹配 + 方差渲染 + 动态建模...）。如何在共享特征骨干上同时实现多维度鲁棒性，而非各自独立模块堆叠，是关键工程挑战。

6. **真实世界验证差距**：WildGS-SLAM及大多数改进方法使用实验室数据集（TUM/Bonn/Replica）或后处理构造的退化（合成噪声、模拟低光）。真实世界夜间驾驶、雨雪天气、工业场景的验证严重不足。
